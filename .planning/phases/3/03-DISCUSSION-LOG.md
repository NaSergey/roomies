## Открытие профиля кандидата

### Триггер

| Опция | Описание | Выбрана |
|-------|----------|---------|
| Тап по карточке | Любой тап по фото/имени = открыть профиль | ✓ |
| Кнопка «Подробнее» на карточке | Свайп — жестом, профиль — иконка «инфо» или кнопка «Подробнее» | |
| Свайп вверх = развернуть профиль | Свайп вверх по карточке разворачивает доп. контент в нижней панели | |

**User's choice:** Тап по карточке

---

### Презентация

| Опция | Описание | Выбрана |
|-------|----------|---------|
| Нижняя шторка (bottom sheet) | Снизу выезжает панель поверх свайп-колоды. Свайп-колода остаётся видна сзади | ✓ |
| Полный экран | Профиль занимает весь экран, колода скрыта. Кнопка «Назад» / Telegram BackButton возвращает к свайпу | |

**User's choice:** Нижняя шторка (bottom sheet)

---

### «Вайб дома» (PROF-02)

| Опция | Описание | Выбрана |
|-------|----------|---------|
| 5 шкал из Vibe Quiz | Тишина, чистота, режим сна, общение, WFH — визуальный прогресс-бар или колесико | ✓ |
| 5 шкал + вайб-теги | Шкалы сверху + чипсы вайб-тегов («кошатник», «ранняя пташка», ...) снизу | |
| Только вайб-теги | Чипсы тегов — быстро и наглядно. Шкалы — в блоке «Почему вы совпали» | |

**User's choice:** 5 шкал из Vibe Quiz

---

### «Почему вы совпали» (PROF-03) — источник причин

| Опция | Описание | Выбрана |
|-------|----------|---------|
| Бэкенд генерирует текст | GET /feed возвращает готовые строки matchReasons: ["Похожий режим сна", "Оба не курят"]. Фронт просто показывает их | ✓ |
| Фронтенд генерирует по данным профиля | Бэкенд шлёт нолевые значения шкал, фронт сам строит по шаблонам: «Режим сна: оба совы» → значения близки | |

**User's choice:** Бэкенд генерирует текст

---

### Кнопки в шторке

| Опция | Описание | Выбрана |
|-------|----------|---------|
| Лайк + Пасс прямо из профиля | Свайпнуть можно не возвращаясь на колоду. Шторка закрывается после действия | ✓ |
| Только посмотреть, свайп — только через колоду | Шторка чисто информационная. Действия — через кнопки на колоде под шторкой | |

**User's choice:** Лайк + Пасс прямо из профиля

---

### % на свайп-карточке (MATCH-06)

| Опция | Описание | Выбрана |
|-------|----------|---------|
| Одна цифра: общий Match Score % | Например «★ 87%». Одна наклейка — просто и понятно. Детали — в профиле | ✓ |
| 2–3 наклейки: отдельные компоненты | Например «Стиль 92%» + «Вайб 78%». Подробнее, но громоздче. Бэкенд должен возвращать lifestyleScore и vibeScore отдельно | |

**User's choice:** Одна цифра: общий Match Score %
