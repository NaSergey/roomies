# Phase 3 — UI Design Contract: Discovery & Profiles

> Visual and interaction contract for Phase 3 frontend implementation.
> Generated by gsd-ui-researcher. All decisions pre-populated from upstream artifacts.
> Extending existing neobrutalism design system — NO new patterns.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Tailwind v4, CSS vars, custom neobrutalism) |
| Preset | not applicable |
| Component library | none (custom components, FSD architecture) |
| Icon library | inline SVG (project-specific, see ActionButtons.tsx pattern) |
| Font primary | Golos Text — `var(--font-golos)` / `--font-sans` |
| Font numbers | Outfit — `var(--font-outfit)` / `--font-age` |
| Design language | Neobrutalism: `border-2 border-black` + `shadow-[4px_4px_0_rgba(20,20,15,0.9)]` |

## Spacing Scale

Tailwind v4 — no `tailwind.config.js`. Use standard Tailwind spacing utilities only.
All values must be multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`) | Icon gaps, inline chip padding |
| sm | 8px (`gap-2`, `p-2`) | Between chips, icon + label |
| md | 16px (`px-4`, `py-4`) | Default section padding |
| lg | 24px (`px-6`, `gap-6`) | Sheet section gaps |
| xl | 32px (`py-8`) | Sheet bottom padding (pb-8 already in FilterSheet) |
| 2xl | 48px | BottomNav clearance (bottom-nav height ~56px + safe area) |
| touch | 44px min | Touch targets — Like/Pass buttons are 60px, Meet WCAG 2.5.5 |

Exceptions:
- Action buttons: h-[60px] w-[60px] (like/pass), h-[56px] w-[104px] (message oval) — from ActionButtons.tsx
- Sheet handle: h-1 w-10 — from FilterSheet.tsx
- Thumbnail strip: h-[66px] w-[54px] — from ProfileCard.tsx

## Компонент: VibeScaleBar

### Описание
Одна вайб-шкала из 5 (noiseLevel, cleanliness, sleepSchedule, socialLevel, workFromHome).
Показывает: иконка + русское название + прогресс-бар.

### Visual Spec

```
Тишина в доме   [████████░░]  80%
```

```
Контейнер: flex items-center gap-3
Иконка: 20px emoji или inline SVG
Метка: text-sm font-bold text-[#14140f] w-[100px] shrink-0
Трек: flex-1 h-2.5 rounded-full bg-[#f0efe9] border border-black overflow-hidden
Заполнение: h-full rounded-full transition-all duration-500
  — 0–40%: bg-[#ffd9e0] (розовый — расхождение)
  — 40–70%: bg-[#ffd7a8] (персиковый — нейтрально)
  — 71–100%: bg-[#c8f36a] (лайм — близко к пользователю)
Процент: text-xs font-black text-[#14140f] w-8 text-right
```

Шкалы и метки (5 штук, порядок фиксирован):

| Ключ | Русская метка | Иконка |
|------|--------------|--------|
| `noiseLevel` | Тишина дома | 🔇 |
| `cleanliness` | Чистота | 🧹 |
| `sleepSchedule` | Режим сна | 🌙 |
| `socialLevel` | Общение | 💬 |
| `workFromHome` | Дома / работа | 💻 |

Если значение шкалы `null` — скрыть строку (не рендерить).

## Компонент: RulesSection

### Описание
Блок «Правила, которые важны»: 3 dealbreaker-пункта (smokingOk, petsOk, guestsPref).

### Visual Spec

```
[✅ Не курят]   [❌ Питомцы ок]   [🏠 Гостей: редко]
```

Каждый пункт — chip:
```
rounded-full border-2 border-black px-3 py-1.5 text-sm font-bold
— Соответствует: bg-[#c8f36a] text-[#14140f] shadow-[2px_2px_0_rgba(20,20,15,0.9)]
— Не соответствует / нейтрально: bg-white text-[#6f6f68]
```

Layout: `flex flex-wrap gap-2`

Маппинг значений:

| Поле | true | false |
|------|------|-------|
| `smokingOk` | «🚬 Курение ок» (white bg) | «🚭 Не курят» (lime bg) |
| `petsOk` | «🐾 Питомцы ок» (lime bg) | «🚫 Без питомцев» (white bg) |
| `guestsPref` | «🏠 Гости: часто» (white) / «👌 Гости: иногда» / «🤫 Гости: редко» |

Примечание: контрастность зависит от совпадения с профилем текущего пользователя —
зелёный лайм = совпадение, белый = нейтрально. Логика сравнения — в фиче, не в компоненте.

## Компонент: FilterSheet (расширение)

### Новые фильтры (добавить к существующим)

**Районы** — мультивыбор, список из `GET /geo/districts`:
```
Row label="РАЙОНЫ"
Chips: динамические из API (districtIds)
Активный: bg-accent shadow-[2px_2px_0...]
```

**Сценарий / Кто ищет**:
```
Row label="КТО ИЩЕТ"
Chips: «Ищу жильё», «Есть жильё», «Ищу соседа», «Сквад»
```

**Dealbreakers** (новые 3 строки):
```

Chips: «🚭 Не курят», «🚬 Курят», «Всё равно»

Row label="ПИТОМЦЫ"
Chips: «🐾 Есть питомцы», «🚫 Нет питомцев», «Всё равно»

Row label="ГОСТИ"
Chips: «Часто», «Иногда», «Редко», «Всё равно»
```

### Кнопка «Применить»

**Было:** `onClose` на кнопке «Показать результаты» (без callback применения).
**Стало:** Отдельный `onApply: (filters: DeckFilters) => void` пропс. Кнопка вызывает `onApply(filters)` затем `onClose()`. `SwipeDeck` вызывает `queryClient.invalidateQueries(['feed'])` в `onApply`.

Текст кнопки: «Применить» (не «Показать результаты»).

Стиль кнопки не меняется:
```
w-full rounded-full border-2 border-black bg-accent py-3 text-sm font-black text-[#14140f]
shadow-[3px_3px_0_rgba(20,20,15,0.9)]
active:translate-x-[1px] active:translate-y-[1px] active:shadow-[2px_2px_0_rgba(20,20,15,0.9)]
```

### DeckFilters тип (расширение)

```typescript
export interface DeckFilters {
  // Существующие
  age: '18-22' | '23-26' | '27-30' | 'all';
  schedule: 'early' | 'night' | 'any';
  cleanliness: 'neat' | 'normal' | 'relaxed' | 'any';
  budget: 'low' | 'mid' | 'high' | 'any';
  // Новые Phase 3

  smokingOk: boolean | null;  // null = any
  petsOk: boolean | null;     // null = any
  guestsPref: 'often' | 'sometimes' | 'rarely' | null; // null = any
}
```

## Interaction Contracts

### Tap card → Open sheet (D-01, D-02)

1. Пользователь тапает на карточку (не драг, а tap < 10px delta).
2. `SwipeDeck` определяет тап через `onPointerUp` delta check.
3. `CandidateProfileSheet` монтируется с `open=true`.
4. Анимация: `translate-y-0` за `300ms cubic-bezier(0.34,1.2,0.64,1)`.
5. Backdrop появляется одновременно (`opacity: 0 → 1`, `duration-300`).
6. Хаптик: `haptic('light')` при открытии.

### Like / Pass из sheet (D-03)

1. Кнопки Like/Pass в sheet — те же `ActionButtons` компонент (переиспользовать).
2. При нажатии: `haptic('medium')`, вызов `useSwipeMutation`, закрытие sheet.
3. Анимация закрытия: `translate-y-full` `200ms ease-in` (быстрее чем открытие).
4. Следующая карточка в deck уже предзагружена (VISIBLE_STACK=3).

### Drag-to-dismiss sheet

1. Touch start на handle или верхних 80px sheet.
2. При drag вниз > 100px: dismiss (translate-y-full, 200ms ease-in).
3. При drag < 100px + release: snap back (translate-y-0, spring cubic-bezier(0.34,1.56,0.64,1)).

### Filter apply (D-10)

1. Пользователь выбирает фильтры (chips переключаются мгновенно, локальный state).
2. Нажатие «Применить»: `onApply(filters)` → `onClose()`.
3. `SwipeDeck` в `onApply`: обновляет `queryParams` state → React Query автоматически рефетчит `['feed', queryParams]`.
4. Индикатор загрузки: skeleton-карточка (белый прямоугольник с `animate-pulse`).
5. Хаптик: `haptic('light')` при нажатии «Применить».

### ProfileEditSheet save (PROF-01)

1. Пользователь редактирует поля (локальный form state в sheet).
2. «Сохранить»: `PATCH /profile` → optimistic update в `useQuery(['profile/me'])`.
3. Закрытие sheet после успешного ответа.
4. Хаптик: `haptic('success')`.
5. Ошибка сети: toast-подобное сообщение (inline в sheet, под CTA: `text-xs text-[#ff6b85]`).
