## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request → ChatController | Client-supplied chatId, message content, call times, agreement action cross here |
| JWT token → user.id | All authorization derives from the verified JWT sub claim, never from request body |
| ChatService → Prisma | Business logic reads match participants; assertParticipant enforces chat access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Elevation of Privilege | GET /chats/:chatId/messages | mitigate | assertParticipant() throws 403 if userId not in match.user1Id or user2Id |
| T-04-02 | Elevation of Privilege | PATCH /chats/:chatId/agreements/:id/respond | mitigate | assertParticipant() + check createdById !== userId to prevent self-acceptance |
| T-04-03 | Tampering | POST /chats/:chatId/messages content | mitigate | @MaxLength(2000) on CreateMessageDto; global ValidationPipe enforces at route entry |
| T-04-04 | Tampering | POST /chats/:chatId/call-invites proposedTimes | mitigate | @IsISO8601({ each: true }) + @ArrayMaxSize(3) prevents oversized payloads and invalid dates |
| T-04-05 | Tampering | PATCH call/agreement action field | mitigate | @IsIn(['accept', 'decline']) on both respond DTOs via class-validator |
| T-04-06 | Information Disclosure | GET /matches — partner data | mitigate | Service only returns matches where user is user1Id or user2Id; partner is derived from match, not from a freeform userId param |
| T-04-07 | Denial of Service | Cursor pagination — arbitrary BigInt cursor | accept | Cursor is used in Prisma where: { id: { lt: BigInt(before) } }; invalid string throws parse error (caught by Prisma, returns 500); acceptable for MVP |
| T-04-SC | Tampering | npm installs | accept | No new npm packages added in this plan |
