## Security Note

All API calls go through the existing apiFetch client with JWT auth. Input from CreateSquadSheet form fields (name, budgetMin, budgetMax) is passed through to the backend POST /squads endpoint which applies class-validator constraints (@MaxLength(100), @IsInt(), @Min(0)). The frontend does no sanitization — that is intentional since all validation lives at the API boundary. The leaveSquad action is guarded on the backend (user must be a member). No PII beyond what the backend already returns is rendered or stored client-side.
