# Requirements: Roomie App

**Defined:** 2026-06-07
**Core Value:** Пользователь получает первые качественные совпадения по вайбу за 3 минуты онбординга и понимает, почему ему показали именно этого человека.

## v1 Requirements

### Onboarding

- [x] **ONBOARD-01**: Пользователь может выбрать один из 4 сценариев (ищу жильё+roomie / есть жильё / ищу roomie / squad)
- [x] **ONBOARD-02**: Пользователь может указать город (обязательно) и предпочтительные районы (чипсы, мультивыбор)
- [x] **ONBOARD-03**: Пользователь может задать бюджет (диапазон), дату въезда и срок проживания
- [x] **ONBOARD-04**: Пользователь может задать dealbreakers: курение, питомцы, частота гостей
- [x] **ONBOARD-05**: Пользователь проходит Vibe Quiz — 8–10 свайп-вопросов без текстового ввода (шкалы: тишина/шум, чистота, гости, режим сна, общение, роль дома)
- [x] **ONBOARD-06**: Пользователь добавляет имя, 2–3 фото, 3 вайб-тега из списка
- [x] **ONBOARD-07**: После онбординга пользователь видит первые мэтчи (минимальная анкета достаточна, профиль дополняется постепенно)

### Matching & Discovery

- [x] **MATCH-01**: Система вычисляет Match Score = Hard (35%) + Lifestyle (30%) + Vibe (25%) + Behavioral (10%)
- [x] **MATCH-02**: Если любой hard-фактор (локация, бюджет, курение, питомцы) конфликтует — score = 0, кандидат не показывается
- [x] **MATCH-03**: Lifestyle compatibility рассчитывается по нормализованным шкалам 0–1 из Vibe Quiz с penalty за сильные расхождения
- [ ] **MATCH-04**: Vibe compatibility считается через cosine similarity embedding-вектора из ответов квиза + вайб-теги
- [ ] **MATCH-05**: Behavioral signals обновляют модель в реальном времени (лайки, начатые диалоги, ответы, feedback)
- [ ] **MATCH-06**: Пользователь видит ленту карточек с % совместимости и 2–3 причинами мэтча
- [ ] **MATCH-07**: Пользователь может свайпнуть «в вайб» (лайк), «сохранить», «супер мэтч», «не моё» (пасс)
- [ ] **MATCH-08**: При взаимном лайке показывается экран мэтча с причинами совпадения
- [ ] **MATCH-09**: Пользователь может открыть фильтры и настроить параметры поиска (бюджет, районы, dealbreakers, вайб-шкалы)

### Profile

- [ ] **PROF-01**: Пользователь может редактировать профиль: фото, имя, вайб-теги, dealbreakers, бюджет, районы
- [ ] **PROF-02**: Детальный профиль кандидата содержит секции: «Вайб дома», «Правила, которые важны», «О себе», «Почему вы совпали»
- [ ] **PROF-03**: Блок «Почему вы совпали» показывает 2–3 причины совпадения и мягкий риск (если есть)
- [ ] **PROF-04**: Roomie Score отображается в профиле с объяснением как его улучшить (+10 за фото, +10 за квиз, +10 за правила, +10 за телефон)

### Chat

- [ ] **CHAT-01**: Чат открывается после взаимного мэтча
- [ ] **CHAT-02**: Пустой чат содержит smart-chips с готовыми вопросами («Как у тебя с гостями?», «Тишина после 23:00?» и др.)
- [ ] **CHAT-03**: Пользователь может отправлять текстовые сообщения
- [ ] **CHAT-04**: Пользователь может предложить слоты для созвона (CallInvite с несколькими временными слотами)
- [ ] **CHAT-05**: Получатель может принять слот или предложить другое время
- [ ] **CHAT-06**: Мягкий nudge если чат молчит 12–24 часа («Хочешь аккуратно напомнить?»)

### Roomie Agreement

- [ ] **AGREE-01**: Пользователь может инициировать Roomie Agreement в чате
- [ ] **AGREE-02**: Agreement содержит пункты: тишина после 23:00, уборка, гости, коммуналка, общие зоны (кухня/ванна)
- [ ] **AGREE-03**: Второй участник может принять или отклонить соглашение

### Squad

- [ ] **SQUAD-01**: Пользователь может создать squad (2–4 человека) с названием, бюджетом, районами
- [ ] **SQUAD-02**: Пользователь может пригласить других пользователей в squad
- [ ] **SQUAD-03**: Пользователь может вступить в существующий squad
- [ ] **SQUAD-04**: Squad-карточка отображается в ленте с общим бюджетом и районами

### Trust & Safety

- [ ] **TRUST-01**: Пользователь может верифицировать телефон
- [ ] **TRUST-02**: Пользователь может верифицировать себя через селфи
- [ ] **TRUST-03**: Пользователь может пожаловаться на другого (спам, фейк, оскорбления, подозрительно, другое)
- [ ] **TRUST-04**: Пользователь может заблокировать другого пользователя

### Notifications

- [ ] **NOTIF-01**: Push-уведомление при новом мэтче
- [ ] **NOTIF-02**: Push-уведомление при новом сообщении в чате
- [ ] **NOTIF-03**: Push-уведомление-напоминание о созвоне
- [ ] **NOTIF-04**: Пользователь может настроить какие уведомления получать

### Feedback & Learning

- [ ] **FEED-01**: После общения пользователь может дать пост-мэтч feedback «вайб совпал?» (1 тап)
- [ ] **FEED-02**: Feedback используется для улучшения алгоритма (behavioral signals)

### Monetization

- [ ] **MONET-01**: Пользователь может купить Boost — поднять профиль в ленте на 12 часов
- [ ] **MONET-02**: Пользователь может разблокировать список «кто лайкнул»

## v2 Requirements

### Advanced Features

- **ADV-01**: Голосовые сообщения в чате
- **ADV-02**: Студенческая верификация (email)
- **ADV-03**: Расширенная аналитика Roomie Score
- **ADV-04**: A/B тест тонов (нейтральный / дружелюбный / зумерский)
- **ADV-05**: Геолокация для поиска людей рядом
- **ADV-06**: «Почти мэтчи» при пустой ленте

## Out of Scope

| Feature | Reason |
|---------|--------|
| Web-версия вне Telegram | Telegram-first стратегия, defer |
| Нативные iOS/Android приложения | Telegram Mini App достаточно на старте |
| Листинги квартир / доска объявлений | Не наш продукт по спецификации |
| Видеозвонки внутри приложения | Высокая сложность, defer |
| Хобби и биографические вопросы | Низкая предсказательная сила — осознанно исключено |
| Философские вопросы в квизе | Усталость пользователей, искажение ответов |
| OAuth / email авторизация | Telegram-first, не нужно на старте |
